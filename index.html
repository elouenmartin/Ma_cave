Configuration IA

Entrez votre clé API Google Gemini (gratuite, sans carte bancaire, créée sur aistudio.google.com).

Entrez votre clé API Claude (Anthropic), créée sur console.anthropic.com. Contrairement à Gemini, chaque analyse consomme un peu de crédit payant sur votre compte Anthropic — utile surtout en secours si Gemini est temporairement limité.

Sauvegarde de la cave

Vos vins sont stockés uniquement sur cet appareil et dans ce navigateur. Si vous changez de téléphone, videz le cache du site, ou désinstallez l'appli, ces données seraient perdues sans sauvegarde. Téléchargez régulièrement un fichier de sauvegarde.
